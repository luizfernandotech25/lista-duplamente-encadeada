# Lista Duplamente Encadeada — Atividade Homer Simpson

Implementação de uma estrutura de dados do tipo **Lista Duplamente Encadeada**, desenvolvida em Java como parte da atividade prática sobre listas encadeadas.

## Objetivo

Implementar e testar operações de manipulação de uma lista duplamente encadeada, utilizando personagens do universo de *Os Simpsons* como elementos.

## Tecnologias utilizadas

- Java
- Apache NetBeans IDE 31
- GitHub

## Estrutura do projeto

```text
lista-duplamente-encadeada/
└── src/
    └── listaduplamenteencadeada/
        ├── No.java
        ├── ListaDuplamenteEncadeada.java
        └── Main.java
```

## Implementação

- **No.java:** representa cada elemento da lista, armazenando o nome do personagem e as referências para os nós anterior e próximo.
- **ListaDuplamenteEncadeada.java:** implementa as operações de inserção, remoção, consulta, exibição e manipulação dos elementos.
- **Main.java:** executa os testes das operações solicitadas na atividade.

## Testes

Foram realizados 18 testes, contemplando as operações previstas na atividade, incluindo:

- Inserção de personagens.
- Remoção de elementos.
- Consulta de elementos.
- Verificação de existência.
- Contagem de elementos.
- Manipulação de listas vazias e com diferentes quantidades de elementos.
- Exibição da lista em ordem direta e inversa.

**Resultado:** execução concluída com sucesso no Apache NetBeans IDE 31.
